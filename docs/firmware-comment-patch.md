# `beacon_ch_sweep.ino` 주석 패치

이 저장소에는 펌웨어가 없다. 아두이노 스케치에서 아래 **두 군데**를 직접 바꾼다.
돌아가는 250줄 펌웨어를 통째로 다시 쓰다 오타를 넣는 쪽이 손해가 크므로 주석만 손댄다.
동작 코드는 건드리지 않는다.

---

## 패치 1 — T4a 판정 기준

"3배" 같은 사전 기준을 세우면 안 된다. 수신기가 세 채널을 어떤 순서·비율로 듣는지는
규격이 정하지 않고 기기마다 다르다.

### 찾을 것 (원문)

```c
// T4a: FIXED(37) 와 CTRL_ALL 을 같은 조건에서 각각 3분씩 돌려
//      초당 수신 개수를 비교한다. channel_map 이 실제로 먹히고 있다면
//      CTRL_ALL 쪽이 대략 3배 가까이 많이 잡힌다.
//      (스캐너는 한 번에 한 채널만 듣기 때문)
//      비율이 1에 가까우면 channel_map 이 무시되고 있다는 뜻.
```

### 바꿀 것

```c
// T4a [정성 보조]: FIXED(37) 와 CTRL_ALL 을 같은 조건에서 각각 3분씩 돌려
//      pkt/s 를 비교한다. CTRL_ALL 쪽이 뚜렷하게 크면 channel_map 이
//      먹히고 있다는 정황, 사실상 같으면 무시되고 있다는 신호.
//      [미검증] 비율의 기댓값은 없다. 수신기가 세 채널을 어떤 순서·비율로
//      듣는지는 규격이 정하지 않고 기기마다 다르다(arXiv 2006.09099: 9대 중 6대).
//      따라서 "3배" 같은 사전 기준을 세우지 않는다.
//      실제 채널 확정은 T4c(nRF Sniffer Channel Index)로만 한다.
```

## 패치 2 — payload 설명의 `channel_id`

파일 맨 위 payload 설명에서 `[2] channel_id` 줄을 찾아 값 목록에 `0` 을 추가한다.

### 찾을 것

```c
//   [2] channel_id      37 | 38 | 39
```

### 바꿀 것

```c
//   [2] channel_id      37 | 38 | 39 | 0 = ALL_CONTROL(모드 표식, RF 채널 아님)
```

---

## 앱 쪽은 이미 맞춰져 있다

- `channel_id = 0` → 화면에 `ALL*` 로 표시해 실제 RF 채널처럼 보이지 않게 했다
  (`MainActivity.kt` 의 `CH_ALL_LABEL`)
- CSV 의 `channel_id` 컬럼은 값을 그대로 쓴다 (`0` 도 `0` 으로 기록)
